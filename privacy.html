Privacy Policy

Last updated: November 2026

Faceless Shorts Engine is a personal automation application operated by @sarvesh_bhele for managing and publishing YouTube Shorts to the connected YouTube channel.

1. Data Collection and Usage

This application connects to the YouTube Data API solely to upload videos, format titles/descriptions/tags, and schedule release times. We do not collect, store, or sell any personal user data.

2. Data Security

OAuth tokens and credentials are encrypted and stored securely solely for the channel owner's automated operations.

3. Google API Services Compliance

Faceless Shorts Engine complies with the Google API Services User Data Policy.
